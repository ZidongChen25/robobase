# CQN-AS 研究阶段性汇报（2026-08-13）

任务:BiGym move_plate（主战场）/ flip_cup / sandwich_remove;方法底座
CQN-AS（coarse-to-fine C51 critic,3 层 × 5 bins,action chunk K=16,
DQfD 式 BC large-margin loss,λ=1)。所有"密封"数字 = 200 episodes、
held-out seeds 800-999、固定 100k 步终点、无选点;同 seed 配对比较。

**TL;DR**:BC loss 的权重可以退到 0.0125（1.25% 功率）而不掉分,但退到
精确 0 会相变式崩塌——它在 demo 邻域执行的是一个 penalty-method 约束,
不是普通的正则。去掉 BC 的尝试（value-space floor 方案）能做到梯度层面
无模仿,但只追平 baseline。文献（DART/MILES）指出根因:demo 太干净,
决策边界上没有反事实证据;而我们证明了 online 数据补不上这个洞。当前
阶段用仿真反事实数据增强直接在 demo 邻域补证据,首批修复后数据的 6 个
run 正在密封评估中,中段读数在基线带上方浮动。

## 第二阶段:BC loss 到底在干什么(机制分析)

### 数学身份:penalty-method 约束,不是正则

BC large-margin 项 `λ·max(0, margin + max_{a≠a_demo} Q(s,a) − Q(s,a_demo))`
的 hinge 结构决定:只要"demo 动作是 argmax"这个约束被违反,梯度就全力
推回,**推力大小与 λ 无关**(λ 只决定它相对 TD 的仲裁权重)。而 TD loss
在收敛点附近梯度趋零。所以任意小的正 λ 在平衡态都能赢下排序仲裁——
这解释了 0.003 仍有效、精确 0 立即崩的相变现象:λ>0 时约束存在,λ=0 时
约束消失,中间没有渐变带。

### λ 的四份工作(实验逐一定位)

1. **兄弟可分辨性**:同一状态下相邻 action bin 的 Q 间隔(top-2 gap)。
   崩塌指纹 = gap 从 ~1.1 塌到 ~0.01(178B/wean0/zero70 同一指纹)。
2. **排序优先权**:保证 demo 动作在 argmax 竞争中获胜。
3. **早期行为塑形**:rfloor 实验(λ=0.0125 从头 + floor)密封 51.5/46.5
   (−26),证明从头就低 λ 不行——高 λ 的前 50k 在塑形,之后才能退。
4. **off-manifold 保护**:压住 critic 对没见过动作的乐观外推(见第四阶段)。

**为什么这是问题**:约束把 argmax 排序钉死后,bootstrap 的 max 算子把
被钉死的排序回灌进 TD 目标——**critic 的不动点本身被 BC 污染**,学到的
是"demo 频率",不是回报。实测:baseline critic 的 Q 与真实 RTG 的
Spearman 只有 0.53-0.66,而去 BC 的 rfloor 达到 0.88-0.90(但行为 −26,
"学得到价值"和"打得出分数"解耦——因为价值不掌舵,λ 站岗)。

## 第三阶段:去 BC 的尝试(GPT 提出的 no-BC 方案)

### 方案数学(档案原文核验)

宪章:禁止一切模仿类项(no BC/margin/FOSD/likelihood/AWR/actor)。demo
动作只允许两种用法:作为 replay transition 的 executed action、作为
Bellman max 的候选。核心构造(Stage 7/39/41/42 递进):

1. **Dense all-bin categorical target**(核心):对每个 replay 样本,
   被执行的 bin 回归 `max(MC return, Bellman target)`,**其余所有未执行
   bin 回归任务最低回报(0)**,损失 = 全部 5 bin 的 categorical
   cross-entropy 之和。反作弊不变式(有单元测试):零回报样本上改动
   action 标签,loss 和梯度完全不变——"梯度层面无模仿"是可证的。
2. **Positive-only gating**:online 阶段只在正回报样本上开 dense 目标,
   零回报样本用普通 Bellman(防止失败轨迹把所有 bin 无差别压平)。
3. **Candidate backup**:bootstrap 的 argmax 在 {critic 贪心 chunk,
   数据里记录的下一 chunk} 二选一——demo 动作作为候选而非标签。
4. **Frozen expert replay**:demo buffer 冻结(9253 条,成功 online
   episode 不回灌),每个 batch 一半固定从这取。
5. 流程:10k demo-only offline 预训练 → 101k online。

### 结果:追平,未跑赢

密封(200ep×4 seeds):**no-BC 配方 66.375% vs 官方 CQN-AS 64.625%**
——与 baseline 同带,无显著优势。(你的记忆正确:这部分没跑赢 baseline。)

### 它跑在截断之前,截断如何影响它

**确认:整条 no-BC 线(2026-07-30~08-04)都在旧制度下跑**(demo 截断
默认 08-03 翻转、真正进 repo 是 08-12 的 R-line commit)。这点很关键,
因为旧制度下 demo 成功后还有 24-28 个连续 reward=1 的尾巴,RTG 高达
11.65-24.5,而 C51 支撑只有 [-2,2]——**93.55% 的 demo transition 目标
钉在顶格 atom 上**。该线自己的最终诊断(A18/A19)承认:配方的稳定性
恰恰**依赖这个饱和**——所有正回报都顶格 = 一个隐式的、极宽的 margin,
"目标的粗糙在这个制度里是特性不是缺陷"。

**截断后**(现制度):尾巴没了,回报变成 γ^(T−t)·1,正目标不再顶格,
隐式 margin 消失。推论(未实测):Stage-43 配方直接移植到截断制度会
失去它的稳定性拐杖,大概率复现"可分辨性塌缩"。这也解释了为什么本周
R-line 的 rfloor(floor 思想的截断制度版)从头跑只有 51.5/46.5。

### 它真的是"纯 RL"吗

**梯度层面是**(不变式经 207 项审计),**结构层面不是**。四个残留的
demo 特权:batch 的一半永远来自冻结的成功-only expert buffer;10k
offline 阶段强制 demo 延续做候选;demo 动作进 bootstrap 候选集;
positive-only floor 在成功-only 的 buffer 上事实上 ≈ demo-gating(该线
自己的 Stage-18 注记:"return-gating 在纯成功数据上就是改名的 BC")。
诚实的定性:**loss 无模仿、数据结构仍供着 demo 的"半模仿 RL"**。

## 第四阶段:文献诊断——demo 太干净,而 online 补不上

### 哪些 paper

- **DART**(Laskey et al., CoRL 2017):经典论证——专家 demo 太干净,
  policy 永远见不到"偏离后如何回来"的状态,covariate shift 导致复合
  误差;解法是采集时人为注入噪声。
- **MILES**(Papagiannis & Johns, CoRL 2024, Imperial):现代版——从
  单条 demo 出发,自监督采集"扰动初态 → 回到 demo"的恢复轨迹喂 BC,
  一条 demo 就能训出鲁棒闭环 policy。我们的深读与对照见
  research_paper.md 附录 S1。
- 同族:SPARTN(NeRF 合成扰动视角)、CCIL(学习动力学合成纠正标签)。
  **全族都把增强数据喂 BC;"喂 critic 学价值"这格在 citation graph
  上是空的——这是我们的位置。**

### 为什么 demo 干净是"价值学习"的死穴(不止是 BC 的死穴)

Critic 要在 demo 隔壁 bin 上给出正确的"低价值"判断,才能让 argmax 稳定
选中 demo bin。但训练数据里**从来没有**"demo 隔壁一步"的样本——干净
demo 全在管子中心。于是 critic 对隔壁 bin 只能外推,而实测外推是**乐观**
的(假上坡:baseline critic 给偏离分支打出比 demo 状态本身还高的 Q)。
λ=1 时这个错误被 BC 约束压着不发作;λ=0 时 argmax 顺着假上坡出走。

### 为什么 online 数据补不上这个洞(你的追问,三个原因)

1. **BC 在时,online 采不到边界样本**:policy 被钉在 demo 管子里,成功
   episode 都是"另一条干净 demo"(self-imitation 复制干净性);偶发的
   探索偏离因为复合误差很快滑到远处——**失败数据都落在远区,决策边界
   (隔壁一个 bin)上仍然没有证据**。实测:v1 时代生成的失败数据离 demo
   流形 7 个单位远,critic 学会了贬远区,近区假上坡纹丝不动。
2. **BC 不在时,采集本身被错误的地图驾驶**:critic 的假上坡指挥 argmax
   走出管子 → 采回来全是失败 → 稀疏奖励下失败只教"我走过的地方是 0",
   不指路 → Q 面塌平 → 更乱走。开环注入 vs 闭环自采,后者是死亡螺旋。
3. **打地鼠**:每条 online 失败只贬值它实际走过的一条路径,而乐观外推
   指向组合爆炸多个方向;被动注入可以一次铺一批围栏。

## 第五阶段(当前):仿真反事实数据增强

### 方法(objective 一字不改,只动数据)

利用仿真的 seed-exact 状态复现,沿每条 demo:
1. 在锚点捕获完整物理状态;
2. 单一 action 维度加一个 coarse-bin 宽度(tanh 空间 ±0.4)的扰动,持续
   4 步;
3. 两种续写:**开环续放**(fence 分支:多数失败,带真实 0 回报)/
   **ground-truth 恢复**(伺服回 demo 参考关节位形:demo 动作前馈 +
   关节误差比例反馈,再续放 demo;gripper 为绝对量不反馈);
4. 全部 episode 带**真实环境回报**注入 replay buffer,critic 用原损失
   自己学出邻域价值形状。**同锚配对**里"开环失败 vs 恢复成功"的 33 对
   是信息密度最高的部分——同一扰动状态,两种续写,两种回报。

与 MILES 的本质区别:他们把恢复轨迹当 corrective action 标签喂 BC
(失败增广必须丢弃);我们带真实回报喂 critic(**失败数据是一等公民**,
它画的是价值悬崖的位置)。仿真的严格反事实(同状态、仅一维之差、不同
回报)是真机方法原则上做不到的。

### 重要勘误(研究诚信记录)

本周发现 v1 生成器的 demo 重放从未对齐(错用 executed_action + 双重
tanh 变换),旧反事实数据实为从 reset 起就偏离的 off-manifold 轨迹
(锚前段离 demo 流形距离 7-8,修复后为 0.000)。因此 v1 时代的机制结论
降级为"远区围栏有效"(critic 真贬值 −19~−23%,行为不受损),而
**真正的近区(决策边界)围栏本周才第一次被测试**。生成管线新增铁律:
先过零扰动对照(重放必须能复现 demo 成功)才准生产数据。

### 当前结果

- **v1 远区围栏**(旧数据,机制线):cfaug 密封行为 +0.5(n=2,平),
  held-out 分支复权贬值 −19~−23%(4/4 种子)——"连远区垃圾数据都能教会
  critic 贬值且无副作用"。
- **修复后近区数据(Wave-7,今日密封中)**:fence-v2(120 条开环分支,
  75% 成功/25% 失败的真实邻域形状)×4 种子 + recovery-teach(33 教学对)
  ×2 种子。中段 val50 矩阵(50k-90k):fence-v2 66-82,recovery-teach
  64-84,全员围绕基线带(76)浮动,无一系统性掉队;rt s1 峰值 84。
  **判决以今日密封 200ep 配对为准**(中段曲线按纪律永不作判决)。
- 同期:anneal-A s2 密封 **85.0** = 全线最高单种子(基线最高 82.5),
  在 λ=0.0125 末态取得——"退火到 0.0125"本身已是可用的改进候选,
  4 种子声明门待补 s3/s4。
